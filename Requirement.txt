AGENTIC SDLC FUNDAMENTAL TASK - TASK MANAGER WEB APPLICATION
================================================================

📦 PROJECT DESCRIPTION
Project: "Task Manager" Web App
Create a web application that allows users to manage tasks with basic CRUD operations.

🔧 TECH STACK
Frontend: React.js with TypeScript, Vite, TailwindCSS
Backend: Spring Boot (Java 17+), Maven
Database: H2 (In-Memory)
Communication: REST API with JSON
Build Tools: Maven (Backend), Vite (Frontend)

💡 ENTITY SCHEMA
Task {
   id: number (auto-generated)
   title: string (required, max 100 characters)
   description: string (optional, max 500 characters)
   status: enum ["TODO", "IN_PROGRESS", "DONE"]
   dueDate: date (optional)
}

🔁 FUNCTIONAL REQUIREMENTS

FRONTEND:
- Home page listing all tasks
- Form to add new tasks
- Edit and delete functionality for existing tasks
- Status dropdown for changing task status
- Sort tasks by status or due date (optional)
- Form validations (required fields, character limits)
- Error message display on API failures
- Responsive UI design

BACKEND:
- REST API Endpoints:
  * GET /api/tasks – Retrieve all tasks
  * GET /api/tasks/{id} – Retrieve task by ID
  * POST /api/tasks – Create new task
  * PUT /api/tasks/{id} – Update task
  * DELETE /api/tasks/{id} – Delete task
- Bean Validation (@NotBlank, @Size, etc.)
- H2 database integration
- CORS enabled for frontend communication
- Exception handling and logging
